# Lumi

CLI и skill для исследовательского агента: найти полезные источники относительно твоего
исследования, дополнить библиотеку и помочь разобраться в содержании статей.
Агент отвечает в чате и при необходимости оформляет документ.

Текущий код умеет искать статьи, работать с библиотекой и проверять цитаты. Следующая версия
должна обеспечить надёжный итеративный поиск и чтение, включая сканы, на английском,
китайском и русском. Отдельная проверка датасетов отложена; слой фактов и позиций
удалён вместе со встроенными LLM-воркерами.

## Начать

```sh
sh install.sh                         # установка и настройка API
lumi doctor                           # локальная проверка
lumi init ./research --name "Исследование"
lumi library check --library /path/to/literature
```

Подробности: [установка](docs/installation.md). Все команды: `lumi --help`.
Из исходников: `python3 lumi.py --help` или `python3 -m lumi --help`.

Существующий проект с `literature/` и `research/` (в том числе диплом) работает
без `init` и переноса файлов. Из корня проекта или его вложенной папки:

```sh
lumi status
lumi lookup "export controls"
lumi show pu2026sanctions --pdf-page 1
lumi citations W7203724392
lumi library check
```

Из другой папки: `lumi --project /path/to/project status`. Поиск, `add`, чтение,
цитаты и `library` используют одну библиотеку. Вопросы и журнал поиска остаются
в `research/`; старые записи знания не мигрируются. Подробнее — [совместимость](docs/installation.md#существующая-библиотека).

## Проверить код

```sh
uv run --no-project --with pytest python -m pytest -q tests
```

Исследовательские проекты, PDF и ключи API хранятся вне этого репозитория.
