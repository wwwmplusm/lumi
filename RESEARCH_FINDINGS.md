# Как другие решали критичные проблемы (2026-10-10)

4 субагента, поиск через Keenable (GitHub / HN / Reddit / блоги). **Почти всё — по сниппетам поиска**; целиком прочитаны только quotecheck и README verbatimeter. Ссылки и цифры не перепроверены.

## 1. Напечатанные номера страниц

- **qpdf /PageLabels** (qpdf уже установлен): `qpdf --json --json-key=pagelabels file.pdf` → диапазоны `{index, /S, /St, /P}`; ~20 строк Python. Брать, только если это не тождественное 1..N (большинство статей без меток — marker issue #1002).
- **Метаданные**: Crossref `page` / OpenAlex `biblio.first_page` → сдвиг = first_page − индекс первой страницы статьи в PDF (так делал Zotfile). Ловушки: обложки издателя, препринты без журнальных страниц, номера статей вида «e0123».
- **Колонтитулы**: первые/последние 2–3 строки `pdftotext -layout`, числа и римские цифры → мода сдвига «номер − индекс», принимать при ≥60% страниц. Ловушки: годы, тома, DOI в шапке; первая страница часто без номера. (Zotero 7/8 «Auto-Detect page number»; ebook-toc — медиана сдвига.)
- PaperQA и аналоги печатные страницы не решают — указывают индекс PDF.
- **Рекомендация**: PageLabels → колонтитулы, сверенные с OpenAlex first_page (совпало — принять) → только метаданные с пометкой «не проверено» → страница PDF + «проверить вручную». Хранить сдвиг на статью + `page_source` ∈ {pagelabels, header, crossref, manual, none}.

## 2. Проверка цитат в чате (`check`)

- **quotecheck** (github.com/sandovabarbora/quotecheck, Apache-2.0, stdlib; **прочитан**): нормализация в ключ сравнения (регистр, лигатуры, дефисы/переносы, пробелы, диакритика, кавычки) с картой смещений обратно в оригинал; цифры не трогает. Вердикты: `FOUND`, `FOUND*` (две соседние половины, разрыв ≤12 символов — колонтитул внутри фразы), `DRIFT` (≥80% похоже — **не принято**, показывает настоящий текст), `ABSENT`. Пакетный режим: блок-цитаты и ≥6 слов в кавычках из Markdown. Урок: **14 из 16 найденных дефектов — склейки двух настоящих фрагментов**; не ловит ошибки самого извлечения текста (`-layout` склеил колонки).
- **verbatimeter** (Show HN 2026): пословное выравнивание, непрерывные дословные отрезки ≥3 слов, LCS/ROUGE-L, CLI/CI-гейт.
- **due-diligence-agents** (#5, #24): rapidfuzz `partial_ratio`, порог 80; без нормализации пробелов 73–78 → после 99; поиск только на указанной странице 49 → по документу 97.5 → лестница страница → ±1 → документ.
- **instructor CitationMixin**: `regex` fuzzy `(quote){e<=k}`, k от 0 до 5, подменяет цитату LLM текстом источника.
- **Anthropic Citations API**: `cited_text` берётся из документа, а не генерируется — только для документов в API-запросе, в Claude Code чате напрямую не применимо.
- Двухэтапно: строковое совпадение ловит выдуманные цитаты, LLM-судья — настоящие цитаты, не подтверждающие утверждение. «Заставить цитировать + проверить строкой» — то, что реально работает; одна LLM-проверка — нет.
- **Принуждение**: Claude Code Stop hook получает `last_assistant_message`; `{"decision":"block","reason":…}` возвращает Claude исправлять; проверять `stop_hook_active` против зацикливания.

## 3. Хрупкость к «…» и мелким правкам

Лестница (stdlib + опционально rapidfuzz):
0. Нормализация как сейчас + убрать вставки `[...]`, сноски/надстрочные цифры.
1. Точное совпадение: страница → ±1 → документ (→ библиотека через FTS5, ловит перепутанную статью). `exact`.
2. Разбить по `…` / `...` / `[...]`: каждый кусок ≥15 символов точно, **по порядку**, разрыв ≤~1500 символов. `exact_segments` (soak, benwhalley.github.io/soak).
3. Нечётко: `partial_ratio_alignment` или `difflib.SequenceMatcher` по окнам; ≥90 + высокое покрытие слов → `near_verbatim`, 80–90 → `needs_review`, <80 → `not_found`.
4. Хранить оценку, найденный фрагмент, область поиска; показывать diff.
- Не принимать нечёткое совпадение для цитат < ~40 символов. Порог `fuzzysearch` — пропорционально длине (5–10%).
- Hypothesis fuzzy anchoring (diff-match-patch): дешёвый поиск кандидата → принятие по diff с сохранённым текстом.

## 4. Утверждение следует из цитаты?

- LLM при пересказе научных фраз **повышают уверенность в 37–64% случаев** (arXiv 2606.07951), добавляют причинность к корреляциям (Nature Hum. Behav. s41562-026-02553-x) — это класс «преувеличено».
- Локальные NLI-модели (LLM-AggreFact, balanced acc.): MiniCheck-7B 77.4, Claude-3.5 Sonnet 77.2, FactCG-DeBERTa-L 77.2, MiniCheck-Flan-T5-L 75.0, AlignScore ~72.5, HHEM-2.1 ~71.8. Требуют torch, ~3 ГБ — **пропускаем** (минимум зависимостей).
- LLM-судья: GPT-4o-mini ~7% ложных срабатываний против 50–100% у embedding/NLI-сходства; но дрейф оценок, «ловушка беглости»; few-shot на размеченных примерах (FaithJudge) лучше.
- **Слоистая схема**:
  - L0 (regex, бесплатно): пропавшие оговорки (may/might/suggest/associated/correlat), причинные глаголы не из цитаты, «some» → «most/all», отрицания, **новые значимые слова/имена не из цитаты** (ловит склейку с других страниц). Числа — уже есть.
  - L2 (изолированный воркер): видит только цитату + утверждение; метка exact / overstated / unsupported + неподтверждённый фрагмент; few-shot на 7 известных ошибках; на всём, что пометил L0, + 10–20% случайно.
  - Калибровать на 40 утверждениях аудита (мало — пополнять разметку).
