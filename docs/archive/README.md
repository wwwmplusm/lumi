# Архив Lumi

Эти файлы сохранены для истории. Они не являются текущими инструкциями или утверждённой
спецификацией. Названия команд, пути, даты, число статей и пороги внутри могут быть устаревшими.

Текущая точка входа: [контекст](../CONTEXT.md) и [проект спеки](../SPEC.md).
Принятые решения: [ответы пользователя](../decisions/2026-11-16-user-answers.md).

`RULES-v1.md` и `SCHEMA-v1.md` описывают удалённый слой знания. В пакет они не входят.

- `CONTEXT.md`, `SCHEMA`-упоминания, `PIPELINE_current.md`, `questions.md`: прежний исследовательский контекст.
- `IMPLEMENTATION_PLAN.md`, `V2_CONTEXT.md`, `DESIGN.md`, `thoughts.md`: прежние планы и варианты архитектуры.
- `RESEARCH_FINDINGS.md`, `chinese_russian_sources_research.md`: прежние исследования возможностей.
- `decisions/`: сохранённые формулировки прежних решений.

Сохранность файла не означает принятие всех изложенных в нём предложений.
