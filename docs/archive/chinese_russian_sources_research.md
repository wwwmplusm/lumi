# Китайские и российские источники для Lumi

Дата исследования: 2026-10-28. Статус: рекомендации, интеграции не реализованы.

## Решение в одном абзаце

Начать с независимых от OpenAlex идентификаторов и импорта метаданных, затем подключить **DOAJ** и вспомогательный поиск **Keenable**. Китайский трек: **AMiner → Wanfang**. После проверки добавочного покрытия — **OpenAIRE, BASE и отдельные OAI-репозитории**. **eLIBRARY** вести как договорной трек. **CyberLeninka не собирать автоматически без письменного разрешения**. Приоритет — оценка полезности, воспроизводимости, прав и сложности, а не измеренная полнота баз.

## Национальные и институциональные дополнения

- **ISCAS/CAS IR:** [Identify](https://ir.iscas.ac.cn/casirgrid-oai/request?verb=Identify), [ListRecords](https://ir.iscas.ac.cn/casirgrid-oai/request?verb=ListRecords&metadataPrefix=oai_dc). Субагент получил реальные китайские метаданные и аннотации. Есть старые записи/ссылки: проверить свежесть и права, не предполагать единый API всей CAS.
- **КарНЦ РАН:** [OAI Identify](http://elibrary.krc.karelia.ru/cgi/oai2?verb=Identify), [описание](http://elibrary.krc.karelia.ru/information.html). Метаданные доступны, машинный policy разрешает повторное использование с атрибуцией. HTTPS имеет проблему TLS, отдельные policy-страницы шаблонные: для полных текстов уточнить условия у оператора. TLS-проверку не отключать.
- **НОРА:** [каталог репозиториев](https://openrepository.ru/repositories), [подключение](https://openrepository.ru/connect). Использовать для обнаружения источников; выходной универсальный API не подтверждён. Контакт: nora@neicon.ru.
- **NSTL:** [официальная интеграция](https://www.nstl.gov.cn/Portal/sy_jkfw.html): Web Service и доставка документов по заявке, dataservices@nstl.gov.cn. Бесплатные национальные лицензии отдельных баз не означают бесплатный API всего NSTL.
- **VIP OA:** [открытая коллекция](https://oa.cqvip.com/paper); бесплатное чтение/скачивание не доказывает доступность API всей VIP.
- **CSTR:** [Open API](https://www.cstr.cn/en/search/openApi/). Подтверждена инфраструктура идентификаторов/метаданных, но не универсальный поиск и fulltext статей.
- **ИСТИНА:** [экспорт собственных данных](https://istina.msu.ru/help/export/), включая BibTeX; подходит для разрешённого импорта.
- **НЭБ rusneb.ru:** [руководство](https://rusneb.ru/upload/iblock/e66/Rukovodstvo_chitatelya.pdf); отдельные открытые издания, не подтверждённый универсальный API статей.
- **НЭИКОН:** [архивы зарубежных журналов](https://arch.neicon.ru/), не национальная русскоязычная библиография. [Объявленные 30 000 ₽/год с 2027 года](https://neicon.ru/about/news/661-dostup-k-arkhivam-zarubezhnykh-izdatelej-2) — доступ к архиву, не API.

## Что не автоматизировать сейчас

| Ресурс | Причина / следующий шаг |
|---|---|
| CyberLeninka | [OAI](https://cyberleninka.ru/oai?verb=Identify) технически работает, но [соглашение](https://cyberleninka.ru/terms.html), версия 24.11.2025, п. 6.2 запрещает автоматизированный сбор, включая метаданные, без письменного согласия. Запросить разрешение и лимиты; прежнюю рекомендацию подключить scraper-MCP без согласования считать снятой |
| CNKI | Универсальный официальный публичный search API не подтверждён; браузерные MCP не заменяют лицензию. Уточнить договорной машинный доступ |
| Math-Net | [Соглашение](https://www.mathnet.ru/php/agreement.phtml?option_lang=rus) требует письменного разрешения на систематическое скачивание, включая метаданные |
| ChinaXiv | [OAI-адрес](https://www.chinaxiv.org/oai/?verb=Identify) вернул сообщение об отсутствии права доступа при HTTP 200. Запросить действующий endpoint/условия; старый [реестр COAR](https://doapr.coar-repositories.org/repositories/chinaxiv) не считать текущим SLA |
| Socionet | Исторически описаны REST/OAI, но современная доступность не подтверждена: DNS-ошибка. Не строить интеграцию по сведениям 2015 года |
| SinoMed / Airiti / ScienceChina | Нужный публичный API не подтверждён. Сайты/услуги DOI не являются доказательством API поиска статей |

## План реализации и критерии приёмки

1. **Основа:** независимые ID и внешние идентификаторы, provenance полей, импорт разрешённых экспортов/PDF. Дедупликация DOI; названия/авторы/год — только осторожное сопоставление. Не склеивать перевод, препринт и журнальную версию автоматически.
2. **Первый пакет:** DOAJ REST + Keenable web-discovery. Любая выдача проходит в журнал и кандидаты, не напрямую в прочитанную библиотеку.
3. **Китайский пакет:** AMiner с явным бюджетом платных операций; Wanfang после ключа, HTTPS и условий. Готовые AI-ответы поставщиков пока не интегрировать.
4. **Расширение:** OpenAIRE, BASE после ключа; выборочный OAI и RePEc при доказанном добавочном покрытии. Не зеркалировать целые базы по умолчанию.
5. **Договоры параллельно:** eLIBRARY, Wanfang, CyberLeninka; запросить QPS/квоты, цену, кэш, локальное хранение, PDF, embeddings/RAG, передачу фрагментов LLM и доступность из нашей сети.

Для каждого адаптера: точный запрос/язык/фильтры, дата и версия API, пагинация, число совпадений базы отдельно от числа полученных записей, исходный ответ, ошибки/неполнота; retry/backoff и лимиты. Статусы метаданных, аннотации, фрагмента и полного текста должны различаться.

**Приёмка:** фиксированный контрольный набор русских/китайских/английских запросов и известных статей; сравнить дополнительные релевантные находки, дубли, доступность разрешённого полного текста, задержку, стоимость и сбои. Успешный HTTP 200 не доказывает релевантность, свежесть или полноту. MCP подключать к агенту; воспроизводимый поиск и журнал — оставлять в Lumi.

## Метод и границы исследования

Два раунда параллельных субагентов, Keenable, адресный веб-поиск, первичные документы и README, точечные публичные HTTP/OAI-запросы. Проверялись также GitHub, Reddit, X, Hacker News и форумы. Основные технические находки пришли из официальных документов и GitHub; полезных дополнительных подтверждений API/тарифов в сообществах почти не найдено.

Примеры обсуждений: [Reddit: трудности доступа к китайским статьям](https://reddit.com/r/ChinaLiuXueSheng/comments/1p171t2/trying_to_access_research_paper_china), [X: CNKI Metadata Export](https://x.com/CNKIOverseas/status/1897114418829516938), [HN: обсуждение агрегирования научных метаданных](https://news.ycombinator.com/item?id=26406059). Это пользовательский опыт/анонсы, не спецификации интерфейсов.

**Не выполнено:** авторизованные вызовы AMiner/Wanfang/eLIBRARY/BASE, испытания найденных MCP/CLI, измерение полноты, покупка подписок, массовая выгрузка, изменения кода Lumi. Сведения о доступности и тарифах — на момент проверки; отсутствие найденной документации не доказывает отсутствия API.
