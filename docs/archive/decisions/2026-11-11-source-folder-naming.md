# Исходное решение об именовании источников

Сохранено при объединении рабочих копий 2026-11-16 из локальной правки прежнего worktree v2. Это историческая формулировка; актуальная реализация и отличия описаны в [V2_CONTEXT.md](../V2_CONTEXT.md), раздел «Именование папки работы».

## Имена папок источников (решение пользователя, 2026-11-11)

Папка источника называется `<ключ>-<внешний ID>`, например `pu2026science-W7203724392`. Цель — чтобы в заметках можно было ставить читаемые ссылки на статью без поиска по ID.

- Ключ: фамилия первого автора латиницей в нижнем регистре, год, первое значимое слово названия (без артиклей и служебных слов), без дефисов внутри: `pu2026science`, `besiroglu2024compute`. При совпадении ключей добавляется буква: `chen2026a`, `chen2026b`. Ключ можно поправить вручную, если автоматический получился нечитаемым.
- Хвост: OpenAlex ID (`W…`), а не DOI: DOI содержит `/` и есть не у всех работ. Если OpenAlex ID нет, хвост из другого идентификатора: `-arxiv2604.17602` или `-local01`.
- Код находит папку по хвосту после последнего дефиса, а не по полному имени. Поиск человеком — по ключу (`pu2026`).
- Имя папки — для человека. Стабильный внутренний ID (см. «Минимальные правила данных») от него не зависит; переименование папки или смена ключа не меняют внутренний ID.
- OpenAlex может объединить дубли, и старый `W…` начнёт перенаправлять на новый. Папку при этом не переименовывать обязательно: новый ID и пометка «объединено с …» записываются в метаданные. В карточке хранятся все внешние идентификаторы сразу: OpenAlex, DOI, arXiv.
